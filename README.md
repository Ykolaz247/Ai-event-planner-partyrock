# AI Event Planning Assistant (PartyRock Project)

## 📌 Overview
This project is an AI-powered event planning assistant built using PartyRock. It generates event plans, checklists, and budget breakdowns based on user inputs such as event type, number of guests, location, and budget.

---

## 🚀 Live App
👉 https://partyrock.aws/u/ykolaz247/py08s7xeN/Ykolaz-Event-Planning-Assistant-Pro

---

## 🧠 Features
- Event plan generation  
- Budget breakdown  
- Checklist creation  
- Theme and vendor suggestions
- Individual Invitation Message and Card

---

## ⚙️ How It Works
Users input:
- Event type  
- Guests  
- Location  
- Budget  

Output:
The AI processes the input and generates structured outputs.

---

## 🧪 Example Use Case
A user planning a wedding Anniversary can input details and instantly receive a full event plan and checklist.

---

## 🛠️ Built With
- PartyRock (AWS Generative AI tool)
